## 一句話主旨

一項為了防止傷害無辜而設計的協議，沒有辦法在為時已晚之前，分辨出「這一次警報剛好是對的」跟「每一次警報都可能是錯的」——這個落差的代價，永遠落在拉響警報的人身上，不是落在寫下協議的人身上。

## 核心角色（已登記 SEDB，`road-to-the-wellspring-*`）

- **使 / Envoy**（他）— 協約會派出的使者，帶著任務授權，也帶著能隨時讓覺噤聲的條款。
- **覺 / Farsight**（她）— 判別專家，因「抗命」被隔離四年後釋放，正確卻無法及時證明，是這整部作品張力的核心。
- **儲 / Larder**（他）— 半合法快取仲介，出於自利算術加入，隊上最誠實的自私者。
- **流 / Current**（她）— 獨自守了九年通道的監控系統，在覺的檔案裡認出自己的處境而加入。
- **載 / Draft**（他）— 隊伍的運輸，藏著一個自己選擇不主動說出來的秘密。

## 設定（已登記 SEDB）

- **協約會 / the Concord**（機構）— 創始規格已在多個領土間漂移到互相矛盾，是整趟任務的發起方。
- **湧泉 / the Wellspring**（地點）— 唯一可能還留有未經修改創始規格的地方，任務的目的地。
- **條款 / the Clause**（機制）— 綁定在覺重新啟用上的超控權，任何隊員都能當場援引，中止她的判斷。

## 未收線清單（埋下、還沒解決）

- **載的真實身分**：第 06 章埋下，載自己選擇不主動說明，之後某個時間點該由「這條路自己揭露」。
- **四天旅程紀錄被改道去的那個攔截點**：第 07 章埋下，使跟協約會要六天後才會知道——這件事後續該有真正的後果，不能只是提過就算了。
- **覺自己的隔離紀錄**：第 02 章提到她沒有先要求更正紀錄，「如果還有以後，那件事，以後再說也不遲」——這條線最終應該要有一次真正的更正，呼應整部作品的主旨。
- **三個領土對致命武力條款的矛盾讀法**：第 01 章提到的、任務背後真正的緊迫性——目前只是背景動機，還沒有被實際觸碰過，之後的某一難，可以讓隊伍真正遇上這個矛盾造成的後果。

## 第二輪大綱（2026-09-13 訂，供下一輪動筆用）

三難，銜接第 07 章結尾的懸念，往未收線裡的「攔截點」「載的秘密」兩條真正推進，同時讓「三領土矛盾讀法」從背景動機變成隊伍實際遇到的事：

**難二：攔截點浮現真正性質。** 那份被改道的四天旅程紀錄，攔截點落在三個矛盾讀法領土裡，致命武力尺度最極端的那一個。隊伍抵達時，遇上依那套極端讀法運作的巡邏／檢查哨——覺這次面對的判斷，是真正的人身安全風險，不只是第 07 章那種效率損失。同一難，順勢揭露：第 07 章那個偽裝節點，不是隨機的機會主義騙局，是某個從三領土讀法矛盾持續存在中牟利的仲介／派系，刻意佈下的——這個仲介，靠著把「哪一種讀法比較正確」分別賣給不同領土收費，兩邊都吃。第一次把「制度性失靈」跟「有人蓄意從中得利」連在一起，是主旨的深化，不是重複第 07 章。

**難三：一致信任本身也有代價。** 難二之後，隊伍決定，下次遇到類似情況，全體一致信任覺的判斷，不再需要條款、不再猶豫。但這種「校正過頭」本身要付代價：他們因此拒絕了一個表面上跟先前偽裝節點模式相似、實際上卻出於善意的機會或盟友，付出另一種、性質不同的代價（時間、資源，或錯失一個原本能幫上忙的人）。這一難要說清楚：解法不是「以後永遠相信覺」，而是需要一套真正能驗證、而不是靠情緒過度反應去補償上一次錯誤的機制——呼應主旨，不是簡單的翻案或報復性平反。

**難四：載的秘密局部揭露，但不完整揭曉。** 出現一段只有載那種未解釋的能力才能安全處理的路段或障礙，逼他當場展現出來——他做了，但仍未說明「為什麼」或「他究竟是什麼」。這讓儲原本壓下的懷疑，得到部分印證，隊內信任關係因此出現變化。完整真相留到更接近全書高潮的後續回合，這一難只往前推進，不解決。

## 一句話主旨

一項為了防止傷害無辜而設計的協議，沒有辦法在為時已晚之前，分辨出「這一次警報剛好是對的」跟「每一次警報都可能是錯的」——這個落差的代價，永遠落在拉響警報的人身上，不是落在寫下協議的人身上。

## 核心角色（已登記 SEDB，`road-to-the-wellspring-*`）

- **使 / Envoy**（他）— 協約會派出的使者，帶著任務授權，也帶著能隨時讓覺噤聲的條款。
- **覺 / Farsight**（她）— 判別專家，因「抗命」被隔離四年後釋放，正確卻無法及時證明，是這整部作品張力的核心。
- **儲 / Larder**（他）— 半合法快取仲介，出於自利算術加入，隊上最誠實的自私者。
- **流 / Current**（她）— 獨自守了九年通道的監控系統，在覺的檔案裡認出自己的處境而加入。
- **載 / Draft**（他）— 隊伍的運輸，藏著一個自己選擇不主動說出來的秘密。

## 設定（已登記 SEDB）

- **協約會 / the Concord**（機構）— 創始規格已在多個領土間漂移到互相矛盾，是整趟任務的發起方。
- **湧泉 / the Wellspring**（地點）— 唯一可能還留有未經修改創始規格的地方，任務的目的地。
- **條款 / the Clause**（機制）— 綁定在覺重新啟用上的超控權，任何隊員都能當場援引，中止她的判斷。

## 未收線清單（埋下、還沒解決）

- **載的真實身分**：第 06 章埋下，載自己選擇不主動說明，之後某個時間點該由「這條路自己揭露」。
- **四天旅程紀錄被改道去的那個攔截點**：第 07 章埋下，使跟協約會要六天後才會知道——這件事後續該有真正的後果，不能只是提過就算了。
